# Smart Pantry 🥬
เว็บแอปภาษาไทยสำหรับจัดการวัตถุดิบและวางแผนใช้ก่อนหมดอายุ พัฒนาด้วย HTML, CSS และ JavaScript แบบไม่ต้องติดตั้งไลบรารี

## เริ่มใช้งาน
- **เปิดในเครื่อง:** ดาวน์โหลด/clone repository แล้วดับเบิลคลิก `index.html` เพื่อเปิดใน Chrome หรือ Edge
- **เผยแพร่ด้วย GitHub Pages:** ไปที่ **Settings → Pages** เลือก **Deploy from a branch**, เลือก branch `main` และ folder `/(root)` แล้วกด Save รอ GitHub สร้างเว็บไซต์

## ฟีเจอร์
- Dashboard สรุปจำนวนวัตถุดิบทั้งหมด ใกล้หมดอายุ หมดอายุแล้ว และยังใช้ได้
- เพิ่ม แก้ไข และลบวัตถุดิบ
- ค้นหาชื่อ กรองหมวดหมู่ และจัดเรียง
- แสดงรายการที่ควรใช้ก่อน (หมดอายุแล้วหรือภายใน 3 วัน)
- รองรับมือถือและเดสก์ท็อป
- บันทึกอัตโนมัติด้วย browser localStorage

## ไฟล์
- `index.html` — เว็บแอปทั้งหมด (HTML/CSS/JavaScript)
- `README.md` — คู่มือใช้งาน
- `REPORT.md` — สรุปโครงงานและแนวคิดคณิตศาสตร์ไม่ต่อเนื่อง

## หมายเหตุ
ข้อมูลเก็บในเบราว์เซอร์ของอุปกรณ์นั้น ๆ เท่านั้น ไม่ซิงก์ระหว่างอุปกรณ์หรือเบราว์เซอร์ และการล้างข้อมูลเว็บไซต์อาจลบข้อมูลนี้ได้ ควรตรวจสอบวันหมดอายุจริงบนบรรจุภัณฑ์เสมอ เว็บนี้ไม่ใช่เครื่องมือยืนยันความปลอดภัยของอาหาร
