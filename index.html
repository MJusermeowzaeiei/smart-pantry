🎓 เกี่ยวกับโครงงาน

Smart Pantry เป็นเว็บแอปสำหรับจัดการวัตถุดิบในบ้านและช่วยวางแผนใช้ก่อนหมดอายุ ข้อมูลจะเก็บไว้ในเบราว์เซอร์ของอุปกรณ์นี้

แนวคิดวิยุตคณิตและอัลกอริทึม

  • เซต: คลังวัตถุดิบคือเซตของระเบียนข้อมูลแต่ละรายการ
  • ตรรกศาสตร์: ใช้เงื่อนไขแยกสถานะตามจำนวนวันคงเหลือ
  • ฟังก์ชัน: daysLeft(x) = วันหมดอายุ(x) − วันที่ปัจจุบัน
  • การเรียงลำดับ: เรียงวันหมดอายุจากน้อยไปมาก เพื่อแนะนำสิ่งที่ควรใช้ก่อน
  • การค้นหา: กรองตามชื่อและหมวดหมู่
ถ้าวันคงเหลือ < 0   → หมดอายุแล้ว
ถ้าวันคงเหลือ ≤ 3   → ใกล้หมดอายุ
กรณีอื่น              → ยังใช้ได้
ข้อจำกัด: เว็บนี้ช่วยติดตามวันที่ผู้ใช้กรอก ไม่สามารถยืนยันความปลอดภัยของอาหารหรือวันหมดอายุจากผู้ผลิตได้ ข้อมูลจัดเก็บในเบราว์เซอร์เครื่องนี้เท่านั้น
